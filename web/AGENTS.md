# Browser presentation

React/TypeScript/Vite gallery and, later, the review workspace. Talk to the
Python application through generated OpenAPI types. Do not call Git, GitHub,
or the analyzer from the browser.

- Theme IDs are `white`, `black`, and `dark_blue`. Dark Blue is the default.
- Tokens live in `src/theme-tokens.json` and `src/tokens.css`.
- Treat PR titles, notes, diffs, and model text as untrusted display content.
